# KVINT

RabbitMQ → MongoDB → REST API. Повторные события не создают дубликатов.

## Запуск

Требуется Docker с Compose:

```bash
docker compose up --build
```

`.env` необязателен; настройки - в `.env.example`.

## Продюсер

```bash
docker compose exec app python -m tools.producer
```

Или с хоста, при установленном uv:

```bash
uv python install 3.13
uv sync --locked
```

Активировать `.venv`: `.\.venv\Scripts\Activate.ps1` в PowerShell или
`source .venv/bin/activate` в Linux/macOS. Затем:

```bash
python producer.py
```

Публикуются четыре звонка: по два для `camp_001` и `camp_002`.

## Проверка результата

```bash
curl http://localhost:8000/campaigns/camp_001/calls
```

## Принятые допущения

- Один процесс FastAPI и один консьюмер как фоновая asyncio-задача внутри него. Сообщения обрабатываются последовательно, `prefetch_count=1`; каждый дополнительный worker запустит свой консьюмер.
- Обработка асинхронная: продюсер ждёт подтверждения публикации, не записи в БД.
- Кампания создаётся с временным названием `Кампания {campaign_id}`; последующие события его не меняют.
- На доставку - одна попытка записи. При временной ошибке БД - задержка 3 секунды и `nack(requeue=True)`. Лимита повторных доставок нет.
- Невалидные сообщения удаляются через `reject(requeue=False)`, без DLQ.
- Невременная ошибка или сбой ack/nack/reject останавливает консьюмер и закрывает канал. Оставшиеся неподтверждённые сообщения возвращает RabbitMQ.
- При остановке консьюмера `/health` отвечает 503. После исправления причины нужен `docker compose restart app`; автоматического рестарта нет.
- Отсутствующая кампания: 404 с `{"detail":"Кампания не найдена"}` вместо HTTP 200 из ТЗ. Существующая без звонков: 200 и `[]`.
- Текущий /health проверяет только свой процесс. Запрос может попасть в здоровый worker и не обнаружить, что консьюмер другого остановился. ПРи запуске с N воркерами 

## Логи и остановка

```bash
docker compose logs -f app
docker compose down
```

Данные сохраняются в volumes. Удалить окружение вместе с данными:

```bash
docker compose down -v
```
